# Pix2Tex Studio 2.0.0

2.0 代的**正式版**：本地 CPU 上运行的 UniMERNet 公式识别，配区域截图与手写画板。
本版是**兼容老版本 Word 的优化版** —— **Word 输出模式**已收敛到 **Microsoft Word
实际支持的 LaTeX 子集**（Word 内部把 LaTeX 转成 OMML，所以"标准 LaTeX 能编译" ≠
"Word 能渲染"；哪些命令能渲染只能实测得出，不能照搬 LaTeX 规范）。

## Word 输出优化（相对 rc2）

Word 模式向 Word 支持子集归一化，让公式在**更旧、更严格的 Word 版本**里也能正常渲染：

- **Unicode 归一化**：把 OCR 混入的非 ASCII 折回 ASCII —— 弯引号 / `′` → `'`、
  Unicode 减号与连字符 → `-`、全角括号逗号 → 半角、清除 NBSP 与零宽字符
  （这一步也顺带改善 SymPy）。
- `\prime` → `'`。
- **双竖线范数**（`\|`、`\lVert`、`\rVert`）→ 命名命令 **`\Vert`**。老 Word 认
  `\Vert`，但不认 `\|` 简写（会渲染成单竖线）。
- **单竖线绝对值**（`\lvert`、`\rvert`）→ `|`。老 Word 会把 `\lvert`/`\rvert`
  当普通文字显示。
- **去掉加粗字体命令**（`\mathbf`、`\boldsymbol`）→ 普通字母。老 Word 无法把加粗
  字体块和 `\Vert` 放在一起渲染，二者只能取其一，这里保双竖线、去加粗。
- **去除冗余分组括号**（如 `\left|{\frac{...}}\right|` 里多余的 `{}`）—— 且都不会
  破坏"命令 / 字母"边界。

## 我该用哪个版本？

- **较旧 / 较严格的 Word**：用 **2.0.0（本版）**，这是针对老 Word 的优化版，渲染
  成功率最高。
- **较新的 Word**（解析器宽松、想要更轻的约束）：**2.0.0rc2** 仍可用；本版两种
  Word 都覆盖，拿不准就用本版。

## 2.0 核心功能

- 纯本地 **CPU** 的 UniMERNet tiny 后端；区域截图、手写画板、公式预览、历史记录、
  诊断、全局快捷键、系统托盘、单实例。
- 自带运行时；**无需** Anaconda、系统 Python、CUDA、云服务或联网。

## 已知限制

- 复杂的**线性代数**公式（大矩阵、多层结构）识别精度有限，这是所选模型自身的上限，
  非本应用的处理问题。
- 安装包**未签名**，Windows SmartScreen 首次运行可能告警；请用 `SHA256SUMS.txt` 校验。
